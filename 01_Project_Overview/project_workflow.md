# Project Workflow

1. Requirements and scenario definition.
2. ER modelling and relational schema design.
3. Table creation with PK, FK, UNIQUE, DEFAULT, ENUM and CHECK constraints.
4. Index design and verification.
5. CSV loading in parent-to-child order.
6. Data validation and stock balance initialization.
7. SQL querying and analytical reporting.
8. Views, triggers and transaction demonstrations.
9. CSV export, backup/restore and final documentation.
