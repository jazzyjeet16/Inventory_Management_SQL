# Screenshot Evidence

This folder contains screenshots supplied by the project owner.

- `database_creation/`: visible database/table listing.
- `table_structures/`: DESCRIBE-style outputs for table columns, types, keys and defaults.
- `query_outputs/`: sample data displayed from project tables.
- `indexing/`, `csv_import/`, `analytical_reports/`, `triggers_transactions/`: reserved for additional evidence as those phases are completed.

See [SCREENSHOT_INDEX.md](SCREENSHOT_INDEX.md) for the screenshot-by-screenshot index.

The screenshots show MySQL command-line style output. They do not prove every row count or successful execution of every project script.

**Schema-name check:** screenshots visibly show `inventory_management`, while repository SQL scripts currently use `inventory_db`. Choose one schema name and use it consistently before running all scripts.
